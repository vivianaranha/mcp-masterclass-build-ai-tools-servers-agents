# Case Study 08 — Retail Operations Agent Fabric

**Created by School of AI**

**Domain:** Retail  
**Drivers:** multiple servers, agent routing

## Assignment
1. identify clients and servers,
2. classify tools/resources/prompts,
3. define stateless request paths,
4. define scopes and identity,
5. define gateway policy,
6. identify MRTR/Tasks needs,
7. define caching,
8. assess third parties,
9. define audit/observability,
10. define scale and failure behavior,
11. define protocol-version assumptions,
12. create a production recommendation.

## Twist
Choose one: auth issuer mismatch, excessive scope, long-running operation, server instance loss, rate-limit spike, third-party server change, or migration from a 2025 session assumption. Update the architecture.

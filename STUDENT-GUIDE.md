**Created by School of AI**

Use the engineering loop **Contract → Validate → Authorize → Execute → Observe → Retry/Task → Operate**.

For every server capability record method/name, schema, read/write impact, required scopes, error behavior, audit event, rate limit and version assumptions.

Do not confuse an LLM choosing a tool with permission to execute it.

# MCP 2026-07-28 Migration Notes

**Created by School of AI**

When migrating older implementations, review protocol sessions/handshakes, sticky routing, HTTP+SSE assumptions, server-initiated request patterns, experimental Tasks APIs, discovery caching, authorization issuer validation, credential isolation and deprecated capabilities.

Do not migrate by simply changing the version string. Validate wire behavior and SDK guidance for the target language.

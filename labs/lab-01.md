# Lab 01 — MCP Foundations & 2026 Architecture

**Created by School of AI**

## Outcome
**Map an AI application into MCP clients, servers, tools, resources, prompts and authorization boundaries.**

## Steps
1. Define the client/server boundary.
2. Define method/name and arguments.
3. Define capabilities.
4. Build the local implementation or architecture.
5. Add validation.
6. Add authorization/security behavior.
7. Add one failure case.
8. Add an audit event.
9. Test stateless/retry behavior where relevant.
10. Define caching/task/extension behavior where relevant.
11. Document migration/production implications.
12. Prepare a short demo.
